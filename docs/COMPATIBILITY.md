# Photo All 联机 · 相机兼容性

这份文档记录各品牌相机通过 USB 连接手机时的工作方式、需要在相机上做的设置，以及 RAW 格式支持情况。

- PTP 部分参考 [libgphoto2](https://github.com/gphoto/libgphoto2) 的 `camlibs/ptp2`，这是目前对各厂商 PTP 扩展记录最完整的开源实现。
- RAW 解码用 [LibRaw](https://www.libraw.org/) 0.22.3（2026-10），由 LibRaw 负责读取 RAW 文件。

> **实测情况**：只有**尼康 Z 6II**（固件 1.70，三星 S23 / Android 16）做过真机测试。其他品牌按 libgphoto2 的做法实现，还没在真机上验证。第一次连接时，请在「设置 → 诊断 → 复制诊断报告」里把报告发回来。

## 一、总览

| 品牌 | 浏览 / 导入 / 删除存储卡 | 边拍边传（联机） | 新照片怎么发现 | RAW 冲洗 |
|---|---|---|---|---|
| 尼康 | ✅ | ✅ 用相机自己的快门拍 | 轮询尼康 GetEvent（0x90C7） | ✅ NEF（HE / HE★ 除外） |
| 佳能 EOS | ✅ | ✅ | 先进入 EOS 联机模式，再轮询 EOS GetEvent（0x9116） | ✅ CR2 / CR3（含 C-RAW） |
| 索尼（PC 遥控） | ❌ 看不到存储卡 | ✅ 照片从相机内存直接传过来 | SDIO 握手后，查属性 0xD215 | ✅ ARW（含无损压缩、YCC） |
| 索尼（MTP） | ✅ | ❌ | — | ✅ |
| 富士 | ✅ | ✅（需选「USB 联机拍摄」） | 不发事件，定时列出文件找新的 | ✅ RAF（X-Trans 由 LibRaw 去马赛克） |
| 松下 | ✅（声明为 Windows MTP 后才能删除） | 视 USB 模式 | 标准事件，加定时查找 | ✅ RW2 |
| OM System / 奥林巴斯 | ✅ | 视 USB 模式 | 标准事件，加定时查找 | ✅ ORF（含 14 位高像素模式） |
| 宾得 / 理光 | ✅ | 视机型 | 标准事件，加定时查找 | ✅ PEF / DNG |
| 徕卡 | ✅ | 视机型 | 标准事件，加定时查找 | ✅ DNG |
| 适马 | ✅ | 视机型 | 标准事件，加定时查找 | ✅ fp 的 DNG；X3F（Foveon）走通用路径 |
| 哈苏 | ✅ | 视机型 | 标准事件，加定时查找 | ✅ 3FR / FFF |

「标准事件」指 PTP 中断端点上报的 ObjectAdded。「定时查找」指一直没收到事件时，每 1–3 秒列一次文件，把新出现的当成新照片。

## 二、各品牌

### 尼康

- **USB**：直接连接即可，相机不需要额外设置。可以用相机自己的快门拍，照片写进存储卡，同时上报 ObjectAdded。
- **事件**：轮询 GetEvent（0x90C7），每 400 ms 一次。Z 6II 会把每个事件在中断端点和 GetEvent 两边各报一遍，所以只读 GetEvent。
- **已知问题**：
  - Z 6II 收到 GetLargeThumb（0x90C4）会卡住 USB 通道，所以大图改为读 JPEG，或读 NEF 里内嵌的全尺寸 JPEG。
  - 相机刚开机的几秒内只报 12 种操作，并拒绝读存储卡。程序会等它准备好再继续，最多等 15 秒。
- **RAW**：
  - **HE / HE★（高效 RAW，Z8 / Z9 / Zf / Z6III / Z50II 等）开源解码器都不支持**，请在相机里选「无损压缩」或「压缩」。拍 RAW+JPEG 时，App 会自动改用同一张的 JPEG 冲洗。
  - LibRaw 0.22 新增了 Z6III、Zf、Z8、Z30（仅标准压缩）。

### 佳能 EOS

- **USB**：直接连接。程序会先发 SetRemoteMode（EOS M 和 PowerShot 用 0x15，其他机身用 1）和 SetEventMode(1)，相机才会上报新照片；断开时复位这两个模式。
- **事件**：GetEvent（0x9116）返回一串记录，每条是「长度 + 代码 + 数据」。新文件的代码是 ObjectAddedEx（0xC181 / 0xC1A7 / 0xC1B6），句柄都在记录的第 8 字节。
- **保持唤醒**：联机时每 60 秒发一次 KeepDeviceOn（0x911D）。
- **RAW**：CR2、CR3、C-RAW 都支持。LibRaw 0.22 新增了 R1、R5 II、R6 II、R8、R50、R100。

### 索尼

- **两种 USB 模式**：
  - **MTP**（「大容量存储」或「MTP」）：可以浏览、导入、删除存储卡，但相机在连接期间通常不能拍照。
  - **PC 遥控**（菜单「USB 连接」→「PC 遥控」，静态影像保存目的地建议「PC+相机」）：可以边拍边传。
- **PC 遥控流程**：
  - 先做 SDIO 握手：0x9201 依次发阶段 1、2，再发 0x9202（协议版本 3.00），最后发阶段 3。
  - 拍完后照片在相机内存里，句柄固定是 0xFFFFC001。必须等 0xD215 属性值（用 0x9209 读取）大于 0x8000 才能读，**太早读会让相机死机**。
  - 程序会马上把照片读到手机，RAW+JPEG 会连读两张。
- **RAW**：普通 ARW、无损压缩 ARW 都支持；YCC 中、小尺寸（伪 RAW）走通用路径。LibRaw 0.22 新增了 A7R V、A9 III、A7C II、A7CR、A6700、ZV-E1、FX30 等。

### 富士

- **USB**：在「连接设置 → PC 连接模式」里：
  - 选「USB 联机拍摄 自动」才能边拍边传。
  - 选「USB 读卡器」或「MTP」只能浏览和导入。
- **事件**：联机模式下富士不发 ObjectAdded，程序每秒列一次全部文件句柄来找新文件（libgphoto2 也是这么做的）；同时把 PriorityMode（0xD207）设为 1。
- **RAW**：
  - X-Trans 是 6×6 排列，胶片引擎自带的去马赛克处理不了。这类文件由 LibRaw 做 X-Trans 去马赛克，输出线性 Rec.2020 后再交给胶片引擎，所以**冲洗比拜耳机身慢**。
  - 冲洗尺寸不超过传感器一半时，用半尺寸去马赛克以省内存。
  - GFX 是拜耳排列，走引擎自己的路径。
  - LibRaw 0.22 新增了 X-T5、X-H2、X-S20、X-T50、GFX100 II、GFX100S II。

### 松下

- **USB**：「PC(Tether)」可以联机拍摄，「PC(Storage)」只能浏览导入。
- **特殊处理**：会话发起方要声明为 Windows MTP（属性 0xD406），相机才开放删除等操作。连接时程序会自动设置，并重新读取设备信息。
- **RAW**：RW2，LibRaw 0.22 新增了 S5 II、S9、G9 II、GH7 等。

### OM System / 奥林巴斯

- **USB**：「存储」或「MTP」模式可以浏览和导入。OM 的专用联机协议（0x948x 系列）这一版还没做。
- **RAW**：ORF。LibRaw 0.22 新解码器支持 14 位高像素合成文件，新增了 OM-1 II、OM-5、TG-7。

### 宾得 / 理光、徕卡、适马、哈苏

都按标准 PTP 处理。RAW 由 LibRaw 读取：PEF、DNG、3FR、FFF、X3F。适马 Foveon（X3F）不是拜耳排列，走通用路径。

## 三、RAW 冲洗的两条路径

1. **拜耳传感器**（绝大多数机身）：LibRaw 只负责读取原始数据（黑电平、白电平、白平衡、色彩矩阵），去马赛克和之后的全部步骤由胶片引擎在 GPU 上完成，这条路径最快。
2. **其他传感器**（X-Trans、Foveon、四色传感器、线性 DNG、索尼 YCC，以及颜色表里还没有的新机身）：LibRaw 先去马赛克，输出 16 位线性 Rec.2020 交给胶片引擎。
   - 亮度同样会对齐相机内嵌的 JPEG。
   - 色温设置在相机色彩空间里重新配平。
   - 这条路径不做 RAW 降噪。

两条路径的结果在电脑上对比过：同一张 Z 6II 的 NEF 分别走两条路径，亮度和颜色基本一致。

**不支持**：尼康 HE / HE★；DNG 1.7 的 JPEG-XL 压缩（需要 Adobe DNG SDK，这一版没编进去）。

## 四、手机端

- Android 10 及以上，需要支持 USB OTG（作为主机）和 Vulkan 1.1。
- **三星**：连着相机时，系统每 2 秒做一次 USB 主机权限检查，没发现有影响。应用退到后台时，靠前台服务防止被冻结。
- **线材**：用 USB-C 对 USB-C 的数据线，或者 OTG 转接头加相机原配线。只能充电的线不行。
- **供电**：部分相机会从手机取电，相机菜单里的「USB 供电」可以关掉。
